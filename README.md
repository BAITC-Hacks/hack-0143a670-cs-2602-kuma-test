# Классификатор обращений

Скрипт на Python для автоматической классификации входных обращений пользователей по категориям (`справка`, `жалоба`, `другое`) и генерации подготовленных черновиков ответов на русском языке.

---

## 📁 Структура проекта

- `messages.txt` — исходный файл с 5 готовыми обращениями.
- `classify.py` — основной скрипт для обработки обращений и формирования ответов.
- `README.md` — краткая документация по запуску и результатам работы.

---

## 🚀 Как запустить

Для работы скрипта требуется стандартный **Python 3.7+** (внешние библиотеки не требуются).

### 1. Запуск с файлом по умолчанию (`messages.txt`)

```bash
python3 classify.py
```

### 2. Запуск со своим файлом обращений

```bash
python3 classify.py path/to/your_messages.txt
```

---

## 📊 Результат работы (Что получилось)

При запуске скрипта для тестовых 5 обращений выводится следующая классификация и черновики ответов:

```text
================================================================================
КЛАССИФИКАЦИЯ ОБРАЩЕНИЙ И ГЕНЕРАЦИЯ ЧЕРНОВИКОВ ОТВЕТОВ
================================================================================

[Обращение #1]
Текст:      Как получить справку о месте учёбы?
Категория:  справка
Черновик:   Здравствуйте! Справку о месте учёбы можно заказать в личном кабинете студента или обратиться в учебный офис (деканат). Срок оформления — от 1 до 3 рабочих дней.
--------------------------------------------------------------------------------

[Обращение #2]
Текст:      В столовой очередь, еда холодная.
Категория:  жалоба
Черновик:   Здравствуйте! Нам очень жаль, что вы столкнулись с давкой и холодной едой. Ваше обращение передано управляющему столовой для проверки оборудования и оптимизации работы касс.

[Обращение #3]
Текст:      Хочу записаться на консультацию завтра.
Категория:  другое
Черновик:   Здравствуйте! Вы можете записаться на консультацию через электронную очередь в личном кабинете или обратившись к администратору. Уточните, по какому предмету или вопросу требуется консультация?
--------------------------------------------------------------------------------

[Обращение #4]
Текст:      Пропал Wi‑Fi в корпусе B.
Категория:  жалоба
Черновик:   Здравствуйте! Спасибо за сигнал. Информация о проблемах с Wi-Fi в корпусе B передана в IT-отдел. Специалисты уже занимаются восстановлением доступа.
--------------------------------------------------------------------------------

[Обращение #5]
Текст:      Где парковка для гостей?
Категория:  справка
Черновик:   Здравствуйте! Гостевая парковка находится возле северного въезда (КПП №2). Въезд осуществляется по предварительному согласованию или разовому пропуску.
--------------------------------------------------------------------------------
```
